# Modül 3: Dış Dünya Entegrasyonları ve API'ler

Bu modülde, modelin internete ve harici servislerin (SaaS, Veri Servisleri) API'lerine erişimini öğreneceğiz.

## İçerik
- **Otonom Web Scraper:** İnternetten dinamik veri çekme.
- **GitHub API:** GitHub repolarını otomatik yönetme.

## Uygulama Kodları
- Otonom Web Scraper: [src/03_web_integrations/web_scraper.py](../src/03_web_integrations/web_scraper.py)
- GitHub Yöneticisi: [src/03_web_integrations/github_manager.py](../src/03_web_integrations/github_manager.py)

## Kurulum ve API Anahtarları
GitHub entegrasyonu için bir [Personal Access Token](https://github.com/settings/tokens) gereklidir.
1. Proje kök dizinindeki `.env.example` dosyasını `.env` olarak kopyalayın.
2. `GITHUB_TOKEN` kısmına kendi anahtarınızı yapıştırın.

## Uygulama
Finansal analiz ve borsa verileriyle çalışan bir otonom asistan.
